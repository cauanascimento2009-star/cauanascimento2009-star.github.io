Sobre o projeto

O projeto Camarote Experience 2026 by: John John foi desenvolvido com o objetivo de criar uma presença visual forte para uma campanha de evento, transmitindo exclusividade, desejo e impacto desde o primeiro contato com o público.

A proposta visual foi construída a partir de uma estética moderna, com contraste marcante, elementos de moda, clima noturno e aplicações pensadas para diferentes canais. O projeto inclui arte principal da campanha, peças para divulgação, identidade aplicada em abadás, materiais promocionais, mockups e comunicação visual para redes sociais.

O que foi desenvolvido

Identidade visual da campanha, key visual, peças digitais, aplicações em abadás, materiais promocionais, mockups, posts para redes sociais e direção visual para fortalecer a experiência da marca.
